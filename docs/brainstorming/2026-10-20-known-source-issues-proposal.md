## Verified gap

The accepted source-selection design permits useful contributions from imperfect documents, but excludes arguments invalidated by their premises. Protocol 3 now separates results from forecasts and enforces each contribution's use. Its source-document task does not receive contrary primary evidence from other captured documents. Its `dependsOnFlaggedAssertion=false` therefore cannot establish independence from an issue known elsewhere.

The offline audit reproduces an allowed attributed hypothesis from EarningsMoat passage p104, whose balance-sheet argument uses a zero-long-term-debt premise. The official 2025 annual report, Note 12, records USD 1.491 billion net debt carrying value and USD 1.5 billion note principal. The actual configured technical fallback would select this MiMo qualification after DeepSeek's invalid output on that document. This makes the gap relevant to the configured route order. No analytical claim has been persisted from the experiment.

Capital Blueprint p63 separately contains the incorrect USD 10.47 billion cRPO amount, against USD 12.64 billion in the captured official Q1 release. Its 22.5 percent growth figure is confirmed, so the amount discrepancy alone does not prove its deceleration thesis false. The full quotation still contains a known issue. Independent bundling arguments should remain available.

The original qualification reference tests document purpose, relevance and attribution. It deliberately does not supply the primary accounts to the model. These are application-enforcement findings, not evidence that the task can verify facts without the necessary input. The benchmark reference must never become a production truth database.

## Options

### Add targeted checks and application-owned restrictions

Extend the existing preparation workflow with a bounded comparison of the material contributions being proposed against relevant primary passages already captured. The check is grouped, uses the existing model routes and overall resource envelope, and is limited by the existing input, deadline and attempt bounds. It is not an exhaustive audit of every article. Missing evidence or exhausted allowance leaves the affected contribution as an inspectable lead requiring verification.

Keep the raw qualification immutable. Store check results and evidence-bound issues separately through the existing Convex task-result and preparation owners. Each issue identifies the affected capture, content hash and passage references, the contrary or unresolved evidence, provenance and current disposition. A model concern is not labelled a proven error solely because the model asserted it. Retry or later qualification cannot erase an applicable recorded restriction.

The existing shared usage policy applies restrictions to selection, source reading and attributed-hypothesis creation. An unresolved affected quotation cannot become an automatically proposed argument merely because its original flag is false. Other independent contributions remain eligible under their own restrictions. The existing grouped corpus approval remains the analyst checkpoint. No confirmation is added for each coverage need or internal check.

This accepted option adds a preparation step and persistent check output. Its exact input selection, issue lifecycle, retry fences, resource reservation and old-workflow compatibility must be added to the implementation plan before production coding. It preserves one workflow engine, Convex ownership, existing UI structure, source identity and append-only analyst decisions. Apparent agreement applies only to the comparison actually performed and never certifies a complete document or factual truth. Failure to retrieve comparable evidence cannot count as agreement.

### Keep qualification as preparation and defer automatic attributed proposals

Keep source reading and documentary qualification, but leave unverified external arguments as inspectable leads. Defer automatic attributed-hypothesis creation until a reliable issue-checking boundary exists. This is a smaller prototype slice, but it narrows the currently approved capability and leaves more analytical preparation unfinished. It does not permit presenting the existing comparison as full semantic acceptance.

## Recommendation

Add the targeted check and evidence-bound restriction channel. It directly addresses the demonstrated failure while preserving useful independent material and grouped analyst review. Accepting attribution alone would not enforce the existing imperfect-document rule. Merely adding an empty restrictions field, a fixture-only issue producer or a hardcoded benchmark blacklist would not complete this option.

At its original checkpoint, two runtime attempts were conditional within a cumulative ceiling of 185 and USD 1.
