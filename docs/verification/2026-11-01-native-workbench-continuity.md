## Implemented boundary

New Workbench conversations pin definition version 2 and retain one native Pi conversation across bounded application response missions. Unversioned conversations resolve to version 1, preserving their strict JSON completions and mission-scoped journals. There is no history import, backfill or dependency change. Existing interface composition, research controls and human checkpoints are preserved.

The active mission, generation, writer and epoch fence the shared journal. Publication alone cannot hand it over: the native tail must settle first. Recovery after a crash following publication retains the original task and invocation identity, without new model dispatch under the completed mission. Stopping a response retains queued work and independent research; explicit queue resumption reuses the settled conversation.

Pi owns native submissions, deduplication, steering and compaction. Required current state remains outside lossy summaries, with queued messages excluded. Definition instructions have one rendering owner. The model and Pi validation use the same projected canonical tool schemas; mechanical revisions and uniquely determined message references come from immutable invocation context. Canonical requests and original model arguments remain separate. Server authorization and freshness checks still apply.

Native prose becomes a typed Workbench completion in code; structured definitions remain strict. Tool results expose parsed values and useful refusal diagnostics. Pure pause/resume confirmations use recorded effects and current state, including a pause superseded by a later resume. When the published confirmation differs from the model's text, a native context edit supplies that published answer to later generations while retaining the raw original.

The entire new Workbench Pi journal is bounded to 32 MiB, with 512 KiB commits. Exhaustion stops the conversation explicitly and refuses queue resumption; another message cannot create a replacement journal or reset consumption. Calibration covers effective schema variants, escaped required state and admitted user text through the installed serializer. The complete payload retains its independent 128 KiB check before dispatch.
