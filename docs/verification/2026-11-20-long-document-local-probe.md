Both readings were adopted successfully, and their operation pins refer to different framing revisions. The saved scope and question remained intact.

The first returned range was `[0, 8192)` and the continuation after the save returned `[8192, 16384)`. Each excerpt exactly matched the corresponding normalized-document substring. The second probe used the existing authorized saved-material inspection definition and its real operations over the same immutable capture. The full normalized document was never serialized. No document acquisition was needed on this path. The 70,500-character requested context range deliberately exercises pagination; it is not a recommended default reading size or a claim that a model would choose that range.

## Missing connection and minimal integration direction

The complete requested chain—targeted passage search, contextual read, successful provisional framing save, contextual continuation—cannot currently be exercised as one ordinary pre-Start agent workflow. The actual first Workbench request did not offer `search_available_material`. Its public reader retains an acquired document as operation text and exposes sequential pages, while the saved-material engine expects an authorized capture under dossier/corpus/preparation ownership. The second probe cannot certify that missing connection merely because it used the same file.

The existing owners already provide passage extraction, indexed search, exact quotations, context ranges, pagination and hash verification. The bounded connection to design is to let documents acquired during framing be consulted through that same documentary owner, with framing mission/message/instruction authority instead of requiring a preparation launch. Their document identity and retained bytes must remain authoritative for indexing, reading and later citations; a provisional save alone must not revoke applicable observations. This requires resolving the current representation and ownership boundary, not simply advertising two more tool names or copying their indexing logic into the public reader.

The recommended scope is one shared owner for document access and derived indexes, phase-appropriate authorization, and existing native history/compaction. The probe justifies neither another search engine, automatic model summaries, forced semantic search nor a lower arbitrary context threshold. The existing pre-Start continuation already works locally and should be preserved. Live judgment, hosted full-text relevance, semantic embeddings, long-running accumulation/compaction and the unified cross-phase workflow remain unverified by these probes. Any implementation or paid qualification remains a separate task.
