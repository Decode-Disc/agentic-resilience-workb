## Required next work and capability decision

Documentary preparation remains unacceptable with this Sources model/configuration: both cases produced no controlled contribution. Conversation mechanics and evidence rejection worked, while runtime availability and Adobe's final advice failed acceptance. Independent product work may continue; Sources activation and claims of useful question-led preparation remain blocked.

Independent Architect and Oracle consultation recommends a bounded Sources contract change: the model selects the documentary meaning and evidence; the existing domain owners materialize exact evidence bytes and mandatory completion accounting. The existing passage-key path in `sourceQualification.ts` demonstrates the mechanism but is not a directly substitutable Sources protocol. Evidence selection should resolve a successful retained read/search result and a passage actually returned in that result, using existing operation requests/outcomes and current authority checks. `SourceReviewReads` is a transaction-local database cache, not proof that the model consulted a passage. No new evidence registry is required.

Completion can derive mandatory request references from the need associations already in `data.work` and obtain its revision from the invocation's admitted snapshot, preserving freshness checks against current state. Saved-material reads without a need association must remain explicitly selected when their relevance is a documentary judgment; do not assign every read to every need. Gap versus unfinished work remains a controlled semantic decision. These changes remove the demonstrated transcription and accounting burdens but do not guarantee valid arrays, allowed classification kinds or correct gap judgments. Any accepted change must preserve exact provenance, scoped restrictions, mandatory examination and late-work continuation through native and mission boundaries. This was the proposed contract at diagnosis time. Its subsequently approved implementation is recorded below; no additional paid lot is authorized by this report.

For Workbench, retain the exact Adobe already-started context and contradictory reply as a failing semantic case. Existing domain-owned status and action availability remain authoritative. Any response-control reassessment should use that frozen pair and investigator judgment, without assuming controller scores prove truth or changing thresholds on this example. For local availability, instrument the entry-to-first-database-read boundary and isolate module initialization versus handler execution under the existing query owner before choosing a repair; the current logs do not justify blaming query volume, raising the limit or adding blind retries.
