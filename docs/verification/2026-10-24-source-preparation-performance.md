# Source preparation performance

Date: 2026-10-24. Target: the existing local deployment `local-aboul_panga-dd_proto` at `http://127.0.0.1:3210`. No remote deployment, new live provider request or recovery of the analyst's ServiceNow dossier was performed.

## Implemented behavior

Source review shares immutable evidence reads and validated comparison reviews within one transaction, while preserving the distinction between approved pins and recent draft qualifications. Comparison preparation uses a shared work decision and a versioned context identity covering instructions, response schema, policy, embedding profile and index state. A current result verifies captured bytes, quotations and active authority before reuse, avoiding indexing and search reconstruction. Historical results retain exact-input revalidation. Sources without eligible contributions keep their local not-run result; existing results avoid repeated preparation. Native retrieval batches retain independent capture eligibility and top-64 ranking, with at most eight metadata entries or two lexical capture searches per transaction. Source concurrency remains two and Workflow step sequences are unchanged.

## Native performance evidence

The protected review fixture contains 60 sources, 58 inspected qualifications and four retained comparison records per copied qualification. Five fresh page loads each completed a non-cached `sourceSelectionProposals:getCurrent` execution without an exception. The final executions took 1.25–1.48 seconds including backend overhead, with 0.49–0.57 seconds of user execution, 1,066 document reads and 6,385,817 database bytes each. Cached duplicates are excluded. The [sanitized measurement summary](artifacts/2026-10-24-source-preparation-performance.json) retains each final measurement and the earlier successful run. Its full traces are local-only and are not committed reproducibility artifacts.

The earlier ServiceNow recovery took 522.913 seconds, including 508.344 seconds for comparisons and seven model requests totaling 39.724 seconds of measured provider latency. That observation identifies the original bottleneck; it is not a matched comparison with the illustrative fixture, and no whole-preparation speedup factor is established.
