System time limits and Workbench's `request_approval` operation use the same action catalogue and existing research-control owners. Decisions are idempotent, generation-bound and authorized for the dossier owner; automatic continuation remains bounded by existing capacity, configuration and execution-slot controls. Native conversation history receives the decision exchange while the visible conversation retains the card receipt. Research and Sources views project the same request.

The required deployment setting `SOURCES_PREPARATION_WINDOW_MINUTES` replaces the authored Sources window constant. Agent display names have one shared owner. Settled preparations without usable material, unfinished work and needs on hold remain distinct. Internal recovery reattaches eligible failed time-limit dossiers without resetting allowances. The real ServiceNow dossier has not been reopened; that separate operation still requires the confirmation specified in the plan.
