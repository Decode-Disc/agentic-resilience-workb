## Implemented boundary

New missions pin Pi runtime version 1. Pi owns model/tool continuation, durable task checkpoints, technical history, sleep and automatic compaction. Convex owns the append-only log, single-writer lease/epoch, scheduled recovery wake, authorization, canonical operation dispatch, observations/adoption, publication and cumulative provider accounting. Native Pi transport reuses the existing schema conversion, bounded HTTP, route controls, provider admission and journal; the shared definitions remain the only business operation catalogue. The compatibility driver, registered Workflow paths and pinned generation adapters remain available to retained missions. One-shot source qualification/comparison keep AI SDK transport. Existing analyst-facing pages and conversation message storage are preserved.

The implementation covers capacity-aware FIFO turn selection, common exact earlier-conversation retrieval excluding queued instructions, batches of eight canonical tool calls, generation rebinding of six retained operations, deferred child results and the existing three-turn domain-progress stop. A bounded transaction or host slice does not become a total operation/conversation limit. Required state is supplied outside Pi's lossy summary. Automatic compaction reserves and retains 8,192 tokens each, disables background work and shares invocation receipts/accounting. Exact originals survive compaction and reopening. Replay stops explicitly at 32 MiB retained bytes per mission, with 512 KiB commits, rather than discarding history.

Confirmed replies are reusable after public pause/Resume; unknown dispatched attempts remain reserved and cannot redispatch. Late cancellation/revocation can retain a factual provider receipt without authorizing adoption. Late native work prevents completion, then permits adoption of the same retained proposal after that work settles. A transient persistence failure retries one identical idempotent commit; lost acknowledgements recover the committed key before adopting the projection.
