Keep the candidate inactive. The repairs demonstrate truthful Start confirmation, recoverable intent refusal, useful saved-passage recovery and termination after a concurrent edit. They do not complete business acceptance: the model still fails to register a clear documentary request and changes an analyst-edited question after refreshing its version. Economic framing and a completed second-turn answer remain unqualified in this lot.

A ninth scenario received one call but could not finish before the shared call ceiling. The two company-framing scenarios received no paid call. The eleven passing runner tests assert the experiment's accounting boundary, not eleven successful analyst outcomes.

This is live inference with production domain functions in isolated `convex-test` persistence. It is not deployed-browser inference, general model robustness, summary-fidelity qualification or permission to activate the application route. The cases are familiar development cases, reordered to prioritize status, controls and concurrent recovery within the announced twenty-call ceiling. No retry, fallback, acquisition, route activation, dependency change, commit or cloud deployment occurred.

## Implemented repairs

- Expected Workbench intent, prerequisite and revision refusals use the existing typed operation outcome. Their callers can continue independent work; authority loss and unknown failures remain fenced. A framing edit between claim and effect is refused without overwriting the analyst.
- Native delivery proof checks actual retained message identities and effective tool declarations. It no longer equates immutable submission versions with business-state versions. Admission supplies fresh required state, and dispatch/adoption still check the invocation's current turn version. A rejection inside before-dispatch authorization is recorded as proven not dispatched; failures outside that boundary retain unknown-outcome handling.
- Native input synchronization and cutoff proof now have one cohesive owner, [piNativeInput.ts](../../convex/integrations/piNativeInput.ts), instead of shared phase-local state inside the mission runner. Mere non-completion no longer requests another generation. Three consecutive preparation mismatches stop explicitly rather than yielding and reopening indefinitely.
- Workbench composes explicit Start, pause and resume confirmations from persisted state and effects, preserves independent explanations in mixed-message responses, and includes the retained documentary receipt when registration actually occurred. The published text replaces the final model response in subsequent native context while its raw original remains retained. This does not semantically validate arbitrary prose.
- An unavailable passage returns a specific recovery instruction to search authorized saved material and use an observed locator. Native instructions also clarify a concrete activity proposal and preservation of a refinement's economic relationship. These instruction changes are configuration, evaluated through exact serializer calibration and the live lot rather than a test asserting that prompt wording proves quality.

The [technical contract](../../context/TECH.md) remains the normative owner. The [earlier qualification](2026-11-01-workbench-nemo-requalification.md) and its raw archives are preserved.
