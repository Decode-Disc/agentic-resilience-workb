# Framing an economic inquiry

Consult this method when moving from an analyst's request to a proposed activity and research questions, especially when an announcement could change the program. Read the [worked cases](examples/worked-cases.md) for ambiguous events and the [documentary distinctions](../references/documentary-method.md) for attribution and dates.

Begin with the activity, actors and economic question the analyst actually supplied. Preserve their explicit refinements. Separate their words from a system hypothesis. An analyst's mention of an announcement does not establish that it changes the workflow.

Use the message date and coverage priority to orient discovery. Compare plausible events by their connection to the requested activity, their observed dates and available supporting passages. Read material that can distinguish those interpretations. A newer result can be less relevant; an older release can still explain an explicitly named event. Never describe an event as the latest found when returned observations contradict that statement.

Acquire a useful observed lead or an analyst-supplied URL with `acquire_document`. Use its reading reference with `search_available_material` for a targeted question or `read_in_context` to read from the beginning. Open a returned search reference to see the surrounding passage, and use the returned continuation when more text matters. Cite the exact displayed passage references in a public basis. A reference that opens a document or a later page is a reading instruction and carries no quotation.

Prepare common questions that remain useful across plausible interpretations. Make only event-dependent questions conditional, naming the unresolved condition and its actual basis. Investigate possible economic consequences as questions rather than adding them to the request's premise.

Continue factual checks while they could change the proposed program. When the remaining work is what the program will investigate, present the useful draft and explain how the readings shaped it. If an unresolved distinction materially changes preparation, ask one focused clarification alongside a system-proposed scope. An open event can coexist with a launchable provisional program.
