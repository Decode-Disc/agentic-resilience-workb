# Debug in browser

User would be using `pnpm run dev` in development so the app should be accessible at `http://localhost:3000`.

The otp codes are available in `invitation-otp-codes.local`. Prefer an analyst role for debugging app, and use admin role only for admin specific features.

Use the following tools to access browser:

- `chrome-devtools-axi`: Use this tool by default to debug and fix issues using Chrome's developer tools.
- `agent-browser`: As a fallback if `chrome-devtools-axi` is not available use this one. It provides a simulated browser environment.

## Important:

- You have access to corresponding skill to use the tools correctly. You must use those skills.
